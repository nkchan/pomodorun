# Pomodorun 初版の実装完了

## 目的
途中まで作成された基礎コードを活かし、日本語のmacOSメニューバー常駐ポモドーロアプリを利用可能にする。
ユーザー指定の `/private/tmp/pomodorun-opencode-handoff.md` を詳細要件の原本とし、実装・検証・未署名アプリの生成まで完了する。

## 要件
- [x] R1: Apple Silicon・macOS 13以降で起動し、Dock非表示のTray、残り時間タイトル、左右クリック操作、画面内に収まる約360pxポップアップ、非表示後の常駐、単一起動を実現する。
- [x] R2: 集中25分・短休憩5分・4回ごとの長休憩15分を既定とし、開始・停止・一時停止・再開・休憩スキップを提供する。自然完了だけを計上し、休憩は自動開始、次の集中は手動開始とする。スリープと壁時計変更、設定変更、期限境界、再起動で原本のタイマー仕様を守る。
- [x] R3: アプリ専用ディレクトリにSQLiteで状態を保存し、セッション完了とサイクル更新を原子的に処理する。保存失敗でメモリ状態だけを進めず、二重計上・毎秒保存を避け、タスク論理削除後も履歴を保持する。
- [x] R4: 原本のIPCとイベントを提供し、Rustを状態の正本とする。UIは購読後取得、revisionによる古いイベント排除、再表示時の再同期、利用者向けエラー表示を行う。
- [x] R5: 日本語UIでタスク作成・編集・完了・削除・日付・見積もり・実績・持ち越し表示と、Brain Dump保存・一覧・タスク化・整理を提供する。メモ本文を保持し、タスク化は初期見積もり1で重複作成しない。
- [x] R6: 通知・サウンドの個別設定、OSテーマ追従、時間設定、変更可能なBrain Dumpショートカットを提供する。ショートカット競合時は旧設定を維持し、Esc・フォーカス喪失・閉じる操作では終了せず非表示にする。
- [x] R7: Slackの手動入力ユーザートークンをKeychainだけに保存し、トークン本体・生レスポンスをUI返却・DB・ログに出さない。接続テストは読み取りだけとし、必要権限と保護未適用を表示する。
- [x] R8: Slack Focus Guardはタイマーを妨げず、変更前の復元情報を永続化する。停止・休憩・一時停止・終了・再起動で復元し、手動変更と長い既存Snoozeを保持する。期限切れの曖昧な状態は明示復元操作を提供する。古い処理、部分成功、通信不明、429、認証失敗、再試行、トークン交換・切断は原本の安全条件を守る。
- [x] R9: Rust単体・SlackモックHTTP・Vitest/React Testing Library・TypeScript・Clippy・フロントビルドを実行し、原本の重点ケースを検証する。未実施の実機操作・実Slack試験と自動検証を明確に分ける。
- [x] R10: 未署名のrelease `.app` を生成し、READMEに起動・ビルド・Slack設定・保存先・制約・検証結果・成果物パスを記載する。可能な範囲で起動時間・CPU・メモリも測定する。

- 複数Slackワークスペース・ユーザー、OAuth導入、分析・エクスポート等の追加機能。

## 受け入れ基準
1. `npm install` と `sh scripts/rust.sh fetch` で依存を取得し、ロックファイルを保存する。
2. `sh scripts/rust.sh test`、`sh scripts/rust.sh clippy --all-targets -- -D warnings` が成功する。
3. `npm run test` と `npm run build` が成功する。タイマー境界・DB失敗・復旧・Slack競合／エラー・IPCエラー・メモ操作・イベント再同期を対応するテストで確認する。
4. `npm run tauri -- build --bundles app --no-sign` で未署名ビルドが成功し、arm64の `.app` が生成される。
5. 可能な範囲で生成アプリを起動し、プロセス生存と保存先を確認する。目視や実Slackに依存する操作は実施の可否をREADMEに個別記録する。

## 決めたこと
- 現在の `main.rs` は空で、Reactの `src/`、Slack連携、アイコン、READMEは存在しない。既存のタイマー・DB・型・ビルドラッパーは活かし、未コミットの既存変更を消さない。
- 原本にある安全条件を省略して完成扱いにしない。外部環境が原因で検証不能な項目は、理由と残課題を記録する。
- 原本で指定済みのTauri公式プラグイン、SQLite、HTTP、Keychain、Reactテストの依存を使う。追加依存は原則入れず、Slackモックは既存ライブラリと標準機能で構築する。
- トークン取得や実Slack試験のためにユーザー資格情報を探索しない。ビルドは署名・公証を行わない構成で実行する。
- Rustラッパーは `src-tauri/` に移動するため、Cargoコマンドにルート相対のmanifest指定を付けない。
- 既存Vitest 3系の依存監査で中程度の脆弱性2件が見つかったため、同じ依存を修正版4.1.11へ更新した。更新後のnpm監査は0件。
- 起動時の保存済みショートカット競合やKeychain読取失敗ではタイマーを使える状態を維持し、UIで警告する。
- 実装・自動検証・ビルドは完了。Rust 27件、UI 7件、Clippy・rustfmt・TypeScript・Vite成功。最終 `.app` は8.60MiB、arm64、minimum OS 13.0、Developer IDなしのリンカーad-hoc署名のみ。
- 実機スモークで起動生存、二重起動排除、SQLite整合性を確認。目視操作、Keychain保存、実Slack、macOS 13そのものの動作は未検証であり、チェック済み要件は実装完了を示す。詳細と手動確認手順はREADMEに記録した。
